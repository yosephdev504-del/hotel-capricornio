# Hotel Capricornio - Sitio Web Oficial

Sitio web moderno, responsivo y dinámico para el **Hotel Capricornio**, ubicado en Tela, Atlántida, Honduras.

## 🏨 Características Principales

- **Diseño Moderno y Responsivo**: Experiencia fluida en dispositivos móviles, tablets y ordenadores de escritorio.
- **Sección de Habitaciones**: Visualización detallada de habitaciones para 1, 2 y 3 personas con sus respectivas tarifas y comodidades.
- **Calculadora Interactiva de Reserva**: Permite seleccionar tipo de habitación, número de noches y huéspedes para calcular el total estimado al instante.
- **Integración con WhatsApp**: Enlace directo para reservar y consultar disponibilidad por WhatsApp (+504 9884-2974).
- **Atracciones Turísticas de Tela**: Guía interactiva de lugares cercanos como el Parque Nacional Jeannette Kawas, Jardín Botánico Lancetilla, Punta Sal, Laguna de los Micos y playas de Tela.
- **Preguntas Frecuentes (FAQ)**: Acordeón interactivo con información sobre check-in, políticas de cancelación, mascotas y más.
- **Galería Fotográfica y Reseñas**: Carrusel y testimonios de clientes satisfechos.

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica y accesible.
- **CSS3**: Diseño personalizado con variables CSS, animaciones suaves y diseño adaptable (Grid & Flexbox).
- **JavaScript (ES6+)**: Lógica interactiva para la calculadora, menú móvil, selector de filtros y acordeón de FAQs.

## 🚀 Vista Previa Local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/yosephdev504-del/hotel-capricornio.git
   ```
2. Abre el archivo `index.html` en tu navegador web preferido.
